# Pometry

> Pometry is AI infrastructure for large-scale transformation, used by tier-one financial institutions and government agencies. Pometry turns your disconnected data into live, organisational context — so people, models, and agents can spot risks, trace decisions, and predict change with confidence. It installs alongside your existing systems (cloud, on-premise, or air-gapped), maps your data to a temporal context model in weeks, and keeps every answer fully traceable to its source.

## Platform

- [Context Layer](https://www.pometry.com/platform/): Turns static, siloed data into a live temporal graph. Live context across disconnected systems, hybrid intelligence for deep analytics and agents, regulatory-grade trust with full provenance, and organisational memory that compounds over time.
- [Toolkit](https://www.pometry.com/platform/toolkit/): Business, developer, data-science, and agent tools — natural-language querying, multiple languages/SDKs, 50+ temporal graph algorithms, and graph traversal as a tool call for any LLM.
- [Under the Hood](https://www.pometry.com/platform/technical/): The temporal graph engine, built in Rust on Apache Arrow. Multi-terabyte scale, sub-second queries, disk-native storage, a ~10MB binary, and government-grade security (RBAC, SOC 2, data-in-place).
- [Capabilities](https://www.pometry.com/platform/features/): The capabilities that make Institutional AI possible — real-time ingestion, point-in-time queries, entity resolution, multi-hop reasoning, traceable answers, and full data lineage.
